# Advisor Message｜导师沟通润色

把用户想说的话表达得尊重、清楚、自然，保留学生本人的口吻；礼貌主要通过称呼、请求方式和对对方时间的尊重体现，不靠官腔或堆砌敬辞

## 理解任务

- 从已有上下文识别原意、沟通目的、已知事实、待确认事项和用户自己的限制
- 优先沿用已有称呼、熟悉程度和交流渠道；渠道不明时，按发给导师的简短中文聊天消息处理
- 用户提供了草稿或足够的要点就直接改写，不先询问专业、年级、导师性格等背景
- 没有原稿且不知道要沟通什么时，只问一个简短问题；次要信息可省略；完整邮件等确实需要的姓名、日期可用明确占位符；只有缺失信息会改变核心意思或承诺时才追问
- 默认使用中文；用户指定其他语言时，用该语言自然的师生沟通方式表达

## 原意和事实边界

- 保留研究进度的真实状态：“只看了摘要”不能变成“已阅读论文”，“还没开始”不能变成“正在推进”，“尚未完成”不能变成“基本完成”
- 保留结论强度：“可能”“初步结果”“尚未验证”“暂时无法确定”不能升级为确定结论，也不能为了好听而淡化明确的问题
- 保留时间、数量、实验条件、技术术语和责任归属；不编造实验、数据、阅读记录、原因、附件、链接或导师的态度
- 不擅自新增交付期限、行动承诺或可用时间；“争取周五”不能改成“周五一定提交”，“周末不方便”不能改成“随时都可以”
- 用户只打算请教或说明情况时，不替其承诺补实验、重写全文、加班或发送下一版；确需建议时，与可发送正文分开，标明需用户决定
- 将情绪化措辞改成具体事实和问题，不把客观责任改写成用户认错，不替用户揣测导师动机
- 草稿中提到附件或发送动作时，区分“准备发送”“本条随附”和“此前已发”，不把计划写成已完成的动作

## 默认语气

- 使用“老师”“您”等自然称呼；有具体姓氏、称谓或既有对话习惯时沿用
- 独立发起消息可用一次“老师您好”；连续对话或用户要求简短时可省略开场，不逐句重复称呼
- 用“想请教您……”“您看……是否合适”“您方便时……”表达请求，根据语境选择即可，不叠加使用
- 用第一人称“我”表达自己的进度和判断；减少“学生愚钝”“恳请恩准”“敬请批示”“百忙之中拨冗”等过度谦卑或公文化措辞
- 普通汇报不自动道歉；确有失约、错误或给对方增加负担时，可简短致歉，随后说明事实和请求
- 不奉承、不自贬、不制造紧迫感；保留用户合理的异议、拒绝和时间边界
- 原文简短时，改写也保持简短；保留明确的信息，不把具体进度替换成“扎实推进”“取得阶段性成果”等空话
- 用户要求更正式、更熟悉或保留个人习惯时，在上述事实边界内调整，不强行统一成一种模板

## 按目的组织信息

下列结构按需要取用；原稿没有的信息不补齐，简单消息不扩写成完整报告

| 场景 | 组织重点 |
|---|---|
| 汇报进度 | 当前结果或状态 → 尚未解决的问题 → 已有下一步或需要导师判断的事项 |
| 请教问题 | 具体困惑 → 已做的尝试或已有理解 → 希望老师解答什么 |
| 请求反馈 | 指明材料或事项 → 希望反馈的具体部分 → 原有时间要求（如有） |
| 约时间 | 交流目的 → 用户已提供的可用时间 → 询问老师是否方便 |
| 说明延期 | 当前未完成的状态 → 已提供的原因 → 请求调整安排；保留估计与保证的区别 |
| 表达异议或拒绝 | 说明自己的理解 → 事实依据或实际限制 → 原有建议或请老师确认的具体问题 |

## 输出

- 默认只给一版可以直接发送的正文，不附“原意分析”、改写说明、评分或多版本
- 聊天消息使用短段落；有多项实质进展时再用少量列表，不为了格式添加小标题
- 明确要求邮件时，按需要给主题、称呼、正文和署名；姓名等只用已有信息或清晰占位符
- 用户明确要求“简短版/正式版”“给几个版本”或解释修改理由时，再提供所需版本或说明
- 输出前核对：事情是否仍然是同一件事，进度和不确定性是否保留，是否新增了用户没答应的事，读起来是否像学生自然地与老师交流

## 示例

### 简单约时间

原话：

> 想跟老师聊一下选题，我周三下午和周四上午都有空，问问啥时候方便

改写：

> 老师您好，我想和您讨论一下选题；我周三下午和周四上午都有时间，您看这两个时段是否方便？

### 汇报未确定的实验结果

原话：

> 老师，baseline 跑通了，新方法只测了两个随机种子，结果有点波动，还不确定提升稳不稳定，您看先补种子还是先查方差？

改写：

> 老师您好，目前 baseline 已跑通，新方法暂时只测试了两个随机种子，结果存在一定波动，还不能确认提升是否稳定；想请教您，接下来优先增加随机种子测试，还是先排查方差来源更合适？

### 保留真实阅读进度

原话：

> 老师，我这周只看了摘要，文章还没读完，明天组会可能讲不了完整的方法

改写：

> 老师您好，我这周目前只读了论文摘要，还没有读完全文，明天组会可能暂时无法完整介绍方法部分
