# 机器人工作站组件库

用于选择、描述或补齐可复用工作站组件；这里定义接口与状态责任，实际实现优先复用目标项目已有组件和平台能力，不要求安装新库或采用特定框架

基础按钮、选择器、折叠、菜单与浮层沿用 [组件与反馈](components-and-feedback.md)；需要安排页面时读取 [布局配方](layout-recipes.md)，配色读取 [主题规范](theme-guidelines.md) 与 [可视化主题](visualization-theme.md)

## 复用和接口约定

先找到目标项目实现，核对输入、状态、事件、焦点、失败和资源所有权；样式不合适就调整 token 或局部表现，仅在接口确有缺口时扩展组件，不平行复制第二份业务状态

下表的接口名是职责示例，可映射到现有 props、model、signal 或 Qt 属性；不要求重命名已有 API

每个实际组件就近说明：实现位置、用途、输入与单位、输出事件、受控状态来源、使用 token、适用密度、空/加载/失败表现、键盘方式及资源清理；已有组件文档可直接补齐，不必新增元数据系统

共同规则

- 用稳定对象标识关联列表、图例、树与模型，不能以标签或数组下标当跨组件身份
- 数据状态与操作状态分开，例如 `dataState=stale` 和 `actionState=pending`；故障不伪装成普通空数据
- 动作事件提交用户意图，由原有命令路径判断可用性并执行；组件不能因为进入 selected 或完成动画而直接驱动机器人
- 主题切换只更新表现，不清空输入、改变数据语义或重建有效模型资源
- 所有可操作项保留 hover、pressed、focus、disabled；selected、警告与键盘焦点各自可辨
- 数字使用等宽数字，单位与精度由数据契约确定；不得把未收到的数据默认为零

## 十类组件

| 组件 | 最小输入 / 输出接口 | 必须处理的状态 | Token 与使用边界 |
|---|---|---|---|
| Robot Status Card | 输入机器人 id、真实状态、时间、新鲜度、允许操作与原因；输出现有动作意图 | 未知、断连、就绪、使能、故障；动作处理中与不可用原因独立 | 容器 `surface` / `border-default`；状态取语义族；不以 `brand-solid` 表示已使能 |
| Telemetry Chart | 输入序列 id、语义、单位、时间戳、采样与时间窗；输出时间窗/序列可见性/游标选择 | 加载、无样本、正常、缺口、过期、断流、错误；暂停查看与数据接收分开 | 使用独立 `viz-*`；参考线、图例、线型与单位固定映射，不随序列排序变色 |
| Model Inspector | 输入模型与选中对象 id、属性、数据来源；输出选择、显示层与已有编辑意图 | preparing、visible、paused、failed/lost；空选择与无模型分开 | 外壳用普通表面，视口用 `viz-*`；不拥有第二套 renderer 或模型加载流程 |
| Coordinate Frame | 输入 frame id、父系、变换、长度/角度单位、可见性；输出选择或显示切换 | 有效、选中、隐藏、不可解析、数据过期 | XYZ 使用固定工程映射；文本/焦点用主题 token；不因 Success 或品牌绿色改变 Y 轴 |
| Joint Visualization | 输入 joint id、类型、当前/预览值、上下限与单位；输出现有预览或编辑事件 | 有效、越限、未知、受限、选中；实测与离线预览分开 | Joint Axis 沿用工程色；数值异常用独立状态叠加，不能把整条模型换成品牌色 |
| Connection Indicator | 输入链路 id、连接状态、设备路径、时间、实际原因；输出连接/断开/扫描意图 | 未选择、扫描中、连接中、已连接、断开、失败 | 状态语义族 + 明文标签；扫描结果用原有非阻塞状态浮层，不新增全屏阻塞 |
| Calibration Progress | 输入阶段 id、前置条件、当前阶段、测量/计算/验证结果；输出开始/继续/取消等已有意图 | 未开始、进行中、暂停/等待、失败、已计算、已验证；只有真实通过才显示验证完成 | 普通步骤用中性表面，当前阶段用选中 token，结果用语义族；Reference 不表示成功 |
| Diagnostic Entry | 输入稳定事件 id、时间、级别、对象、消息与上下文；输出选择、复制、定位或已有恢复意图 | info、warning、error；未读、选中、展开与事件级别分开 | `text-*` / `bg-active` 与状态族；选中不覆盖故障标记；大列表复用已有虚拟化能力 |
| Parameter Editor | 输入字段 id、类型、值、单位、范围、来源、dirty、validation；输出修改/应用/保存意图 | 原始、已修改、校验中、无效、只读、禁用、应用/保存中、失败 | 输入表面、`border-*`、`focus-ring` 与错误族；保存成功不等于已应用或已验证 |
| Empty / Loading / Error State | 输入对象名、实际阶段/错误、原因与已存在的下一步；输出重试或导航意图 | 首次空、筛选无结果、准备中、部分可用、失败 | 普通状态用 `text-secondary` / `surface`；错误用错误族；占位不冒充真实设备/数据 |

状态语义族具体的 foreground、indicator、surface、border、icon 角色以主题规范为准；不在组件中散落新的颜色常量

## 组件的必要细节

### 状态卡与连接

卡片先显示对象与真实状态，再显示最近更新时间或过期原因；“已连接”“已配置”“已验证”使用不同字段，不合并成一个绿色完成标记

卡片含多个动作时用独立按钮，不能同时让整张卡片和内层按钮承担不同动作；失能操作仍在原共用操作栏，卡片不复制一套与其不同步的入口

连接按钮与串口选择、扫描保留当前归属；扫描完成、失败和自动关闭时间属于本次操作状态，局部重绘不重置倒计时

### 图表、坐标系与关节

图表说明测量对象、单位、采样时间与新鲜度；缺口不连成可信连续线；用户隐藏序列不会改变其语义色；高频数据复用现有更新节流/绘图路径，先测量再改降采样策略

坐标系必须说明参考父系和单位，方向标签与轴线一一对应；只有显示切换的控件不能暗示已修改真实坐标标定

每个关节的名称、当前值、滑块、数值输入与上下限取自同一记录，label 关联真实控件；未知值明确显示未知；预览事件和真实命令严格沿用已有分离路径

### 检视器、标定与诊断

树选择、模型高亮和属性区以同一对象 id 同步；对象从新模型中消失时清理失效选择，不把旧对象引用用于新模型

标定的“采集完成”“计算完成”“验证通过”“已保存”分别表达，不按步骤动画自动推进；失败允许查看已得到的有效证据，并按原流程重试

诊断条目优先保留事件时间、严重级别与对象；长消息可以展开或复制，不能截掉唯一可定位字段；事件更新不强制用户滚回列表顶部

### 参数与通用反馈

参数输入保留当前项目提交时机、范围校验与单位换算；失焦、展开收起、密度或主题切换不丢输入；保存后按真实结果清理 dirty 状态

初次加载可替换主要内容；已有有效数据刷新时按实际情况保留数据并标记刷新或过期，不反复用 skeleton 闪掉整个面板；重试只重试对应失败责任，不重新触发无关命令

空状态可使用小型工程图形，但正文必须说清对象与下一步；没有恢复动作时不给无效按钮；首屏模型失败且 Profile 可编辑时保留编辑入口

## 实际组件验收

对本次涉及组件检查真实状态、双主题、适用密度、窄窗口、长名称、单位和键盘路径；资源型组件同时检查暂停/恢复和卸载清理；按 [验证](verification.md) 提交与影响面相称的证据，不因组件表列出某类状态就扩大全应用测试范围
