# 视觉资产、背景与效果

用于选择、制作、复用或分发 SVG、工程示意、图表和模型等资产；先判断它解释什么，再决定资产类型，不以填满空白或营造科技感为使用理由

页面构成见 [视觉方向](art-direction.md)，图标制作见 [SVG 规范](iconography-and-svg.md)，图表和模型映射见 [可视化主题](visualization-theme.md)

## 六类资产及其元数据

共同最小记录：资产 id 与相对路径或实现位置、类别、用途及非适用范围、作者/来源和版本、许可与署名要求、真实/示例/示意属性、主题适配方式、尺寸或数据单位、语义颜色、加载与资源责任；可直接写在已有资产文档、组件说明或下方登记表，不强制另建 manifest

| 类别 | 适用内容 | 除共同信息外需说明 | 主题与运行约束 |
|---|---|---|---|
| Interface Assets | 通用 SVG、状态图标、空状态小图形 | viewBox、尺寸、stroke/fill、装饰或语义角色、名称 | 单色 UI 用 `currentColor` 与语义 token；16px 检查；无后台动画与外部字体依赖 |
| Engineering Diagrams | 坐标系、运动链、通信拓扑、传感器关系 | 参考系、方向、实体 id、连接含义、单位、示意或实时状态 | 工程色保持不变；箭头、字母和文字共同表达；拓扑变化才更新结构 |
| Data Visualization | 曲线、误差带、频谱、热力图、仪表 | 数据来源、语义、单位、时间窗、采样/缺失规则、图例 | 独立 `viz-*`；固定语义映射；更新批次和采样沿用项目策略 |
| 3D Visualization | 模型、坐标轴、COM、参考叠影 | 模型身份、资源来源、尺度/单位、坐标约定、共享/独占资源与失效条件 | 独立视口；沿用预加载、跨页保留、隐藏暂停与按所有权释放契约 |
| Atmosphere & Surface | 工作区低对比度网格、局部纹理与背景 | 对空间理解的用途、覆盖区域、透明度、合成背景、实现方式 | 默认静态；不降低文字、曲线或报警对比度；主题与减少透明度偏好可回退为平面 |
| Brand Assets | 已有 Logo、产品标识与批准的品牌图形 | 真实权利方、正式变体、留白与最小尺寸、授权范围 | 使用批准变体；不把普通图标当硬件标识，不将旧品牌素材颜色写回全局 token |

外部资源必须核对具体文件的许可，仓库根许可不自动覆盖字体、图片和内嵌图形；来源未核实的候选可以列为待查，不随 Skill 分发；占位图与示例数据明确标记其性质

## 背景、效果与场景预算

默认预算是平面表面、细微边界、克制阴影与零个装饰性连续动画；普通面板不额外创建 canvas、shader 或独立渲染循环

| 场景 | 允许的效果 | 预算与回退 |
|---|---|---|
| 普通面板/数据表 | 静态表面与边界 | 不加逐帧背景；需要纹理时使用可复用小资源，不覆盖关键文本 |
| 模型工作区 | 解释空间的网格、原点、选择与参考叠影 | 复用现有 renderer 和资源；静止时按需绘制，隐藏时暂停；不为背景增加第二个 WebGL 上下文 |
| 图表 | 必要误差带、阈值区间与事件标记 | 不用流光、装饰渐变或无限闪烁；标记复用图表更新路径，缺口明确表达 |
| 局部空间解释 | 对任务有帮助的 shader/场景 | 只在此区域启用；说明受益对象、最大同时实例和项目允许的资源预算；不可用时提供静态图或文字 |
| 状态过渡 | 已有 hover、focus、切换和短 spring | 沿用 [动效](motion-and-scroll.md)；状态立即提交，不等待效果，不给普通遥测刷新重播入场 |

若确需新增效果，先记录同设备、同窗口/DPI、同模型/数据下的空闲 CPU/GPU、绘制次数、资源数和帧耗时，再比较最终结果；项目已有性能预算优先；没有测量就不宣称“零性能影响”或通用 FPS 保证

将最大同时实例、像素比、几何/粒子量或纹理尺寸限制写在实际实现处，选取与目标硬件相符的数值；没有这类效果就不新增参数系统或虚构预算数值

窗口隐藏或所在页面不可见时停止 RAF、定时绘制与不可见交互；窗口缩放按最新容器合并更新；主题切换只改材质/样式，不重建有效几何或数据订阅；具体资源职责见 [模型生命周期与性能](model-lifecycle-and-performance.md)

`prefers-reduced-motion` 下去除非必要连续变化并保留静态状态；减少透明度时改用不透明表面；GPU 不可用时保留数据和操作，不用黑画布掩盖失败

## 资产验收

检查来源与许可、真实/示意属性、主题与最终合成背景、尺寸、文字可读性、必要非颜色编码以及失败回退；高频或资源型资产检查暂停、恢复、清理和同条件性能；本包资产文件存在不等于其在目标产品中的渲染已通过，实际验收见 [验证](verification.md)
