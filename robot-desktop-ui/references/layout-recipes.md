# 布局配方与选择条件

用于从页面任务落实正文布局；先用 [页面视觉方向](art-direction.md) 分类，窗口外壳、导航层级和四象限操作栏仍由 [布局与导航](layout-and-navigation.md) 定义

配方描述内容关系，不替换既有页面路由、折叠、菜单和机器人状态机；以下宽度均指扣除窗口外壳、侧栏和页面内边距后的实际容器宽度

## 选择顺序

1. 固定外壳、页面标题、导航与本页必要操作；机器人工作页先保留顶部连接工具及共用操作栏
2. 按主任务选 D / W / T / C / G / K / I，不按喜好随机抽取；已有符合任务的布局优先延续
3. 为树、字段、图表图例、详情和动作组确定最小可读宽度；宽度由实际长标签、单位与控件决定
4. 宽容器放入所有必要栏；不足时按配方指定顺序移动辅助区到下一行，再把主区改为单列
5. 检查滚动、焦点、sticky 遮挡与底部可达性；根据实际容器判断，而非只看屏幕分辨率

主数据区使用 `minmax(0, 1fr)` 或等价布局，允许长文本正确换行；普通页面不得用整个页面横向滚动来掩盖不合适的栏宽；密集工程表格可在有名称和键盘入口的局部区横向滚动

## 配方表

| ID / 类型 | 宽容器结构 | 空间不足时的确定性重排 | 保持的阅读顺序 |
|---|---|---|---|
| D / Dashboard | 全宽下一步与进度 → 全宽状态概览 → 主数据；可选状态详情在主数据旁 | 状态概览四列转两列再单列；状态详情移到主数据下；工具与记录始终全宽在后 | 下一步 → 准备状态 → 主数据 → 工具与记录 |
| W / Workspace | 共用操作栏 → 左模型、右任务；右侧包含统一子页导航与当前任务 | 先将任务移到模型下；操作栏按原语义分组换行，停止和失能操作保持可见 | 状态与操作 → 模型 → 当前任务与结果 |
| T / Telemetry | 时间范围与数据状态 → 主图 → 指标与局部数据表；需要时指标栏置于主图侧 | 指标栏移到图下；图例换行或成为可滚动列表；表格局部滚动，不压缩单位到不可读 | 数据来源与时间 → 主图 → 指标 → 明细 |
| C / Configuration | 全宽 Profile / 保存上下文与检查区 → 约 180px 分组导航 + 当前组字段 | 配置容器约 650px 以下改为单列，导航变可换行横向组；字段按实际最小宽度换列 | 保存上下文 → 检查 → 分组 → 字段与校验 |
| G / Diagnostics | 过滤与时间范围 → 日志或告警主区 + 选中项详情 | 详情移到主区下；保留选中对象和列表滚动位置；必要时用已有详情页返回机制 | 筛选 → 事件 → 选中事件详情与相关动作 |
| K / Calibration | 共用操作栏 → 阶段与当前条件 → 测量/模型预览 + 当前步骤；结果在流程后 | 当前步骤跟随阶段；预览与数据上下排，结果完整进入正常流；保留继续/取消及安全操作 | 操作条件 → 当前阶段 → 测量证据 → 计算/验证结果 |
| I / Model Inspector | 工具 → 对象树约 208px + 视口 `minmax(320px,1fr)` + 检视器约 280px → 关节预览 | 模型容器约 900px 以下检视器另起一行，约 600px 以下树也另起一行 | 工具 → 对象结构 → 模型 → 属性 → 关节预览 |

D 的可选状态侧栏只放简短状态或详情；准备流程与“工具与记录”沿用原有全宽结构，不恢复已被移除的窄工具栏

数值阈值来自既有布局基线；移植到其他字体、Qt 或不同最小窗口时，用实际内容复核转折点，维持相同语义重排顺序

## 操作栏不参与视觉抽签

W、K 及已有机器人工作页继续共用原四象限：左上状态，右上使能 / 停放并失能 / 立即失能，左下刚性保持 / 柔性恢复 / 清除故障，右下当前操作条件提示

品牌样式从 [主题规范](theme-guidelines.md) 读取；命令可用条件从 [机器人状态与连接](robot-state-and-connection.md) 读取；配方不得改变命令含义、移动危险操作到隐藏菜单或把条件提示塞进按钮组

## 密度与持续工作上下文

Default 是普通工作页起点；Telemetry 和 Diagnostics 可选 Compact，低频引导可选 Comfortable；密度的字号、行高、控件高度与间距应整体切换，具体 token 见 [设计系统](design-system.md)

Compact 不缩小安全操作命中区，不截掉数值单位，不删除字段校验；同一编辑会话切换密度保留字段值、选择、滚动和焦点上下文

可调整栏宽的项目沿用已有 splitter 和持久化规则；不为固定布局任务额外引入拖动布局系统；拖动后仍保证每栏最小可读宽度

树、日志或长表确属局部工具时才独立滚动；三维视口有明确可用高度；关节列表和结果区进入正常页面流，检查固定高度、`overflow:hidden/clip` 与 sticky 祖先是否截断末尾内容

## 布局与资源分离

移动、折叠或换行只改变展示容器，不重新创建模型、图表数据订阅或异步请求；共享模型资源与每场景相机/选择分别保留，生命周期见 [模型生命周期与性能](model-lifecycle-and-performance.md)

以实际常规窗口、最小支持窗口和高 DPI 检查标题起点、操作可达、长名称、长错误与底部控件；截图覆盖与行为证据按 [验证](verification.md) 选择
