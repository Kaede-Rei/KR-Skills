# 动效、切换与滚动连续性

按 SerialArm-Core 的已确认行为处理页面、子页面、选择状态、菜单和折叠；视觉过渡使用可中断的临界阻尼 spring，动作与真实状态立即生效

组件形态见 [组件与反馈](components-and-feedback.md)，层级与导航见 [布局与导航](layout-and-navigation.md)；动效评审流程见 [工作方式](workflows.md)

## 选择目标

- 用连续运动解释“从哪里到哪里”，保持操作对象与空间关系清楚
- 页头、导航、机器人操作栏、三维画布和终端是稳定区域；正文切换时不一起漂移
- 指针、按键、命令发送与焦点处理不等待动画结束
- 快速切换、反向展开和连续选择都从当前呈现状态继续，不能跳回预设起点
- UI 切换采用短 spring；直接拖动按输入 1:1 更新，遥测读数按真实数据更新
- 不给实时数值补插值来制造“平滑”，也不让退出动画拖延安全操作

## 两组 spring

现有体系沿用 ATIL 的速度尺度，将阻尼比统一为 1；采用临界阻尼以避免弹跳

| 用途 | response，单位秒 | 对应尺度 |
| --- | --- | --- |
| 快速反馈、指示器、浮层、折叠箭头 | `2 * Math.PI / Math.sqrt(900 / .7)`，约 `0.175` | `stiffness=900`、`mass=.7` |
| 新正文进入、面板高度 | `2 * Math.PI / Math.sqrt(560)`，约 `0.266` | `stiffness=560`、`mass=1` |

`response` 定义系统的响应尺度，不是“到点强制结束”的固定 duration；结束条件同时看剩余位置误差和速度

不要把 spring 等同于某条万能 `cubic-bezier`；固定起终点的 CSS easing 不能自行保留中途速度

技术栈已有支持打断与速度继承的 spring 时直接复用；原生 DOM 项目可沿用一个小型共享驱动器，不为每个控件建立一套引擎

下面是单个标量的临界阻尼精确步进；调用者保存返回的 `value` 与 `velocity`，重定向时只改 `target`

```js
function stepSpring(value, velocity, target, response, dt) {
  dt = Math.max(0, dt);
  const omega = 2 * Math.PI / response;
  const offset = value - target;
  const carry = velocity + omega * offset;
  const decay = Math.exp(-omega * dt);
  return {
    value: target + (offset + carry * dt) * decay,
    velocity: (velocity - omega * carry * dt) * decay,
  };
}
```

`dt` 使用秒；必要的范围约束由具体属性定义，触及硬边界时同步清零该轴速度；没有活动动画时停止 RAF

## 页面与子页面切换

使用稳定的页面或子页面 key 判定内容变化；先同步替换业务正文，再让符合条件的新内容进入

1. 记录目标 key、正在进行的呈现进度与速度，以及需要恢复的导航焦点
2. 同步移除旧正文，完成新正文的事件绑定和编辑状态恢复
3. 新正文由最多 `8px` 的纵向位移回到原位，透明度从 `.68` 到 `1`
4. 以面板 spring 驱动进度，结束后清理临时样式和标记

这是一套正文，不保留旧正文的截图、克隆或退出层；不通过 blur 掩盖两套文字重叠

- 相同 key 的状态刷新不重播进入动画
- 子页局部刷新后同步外围页面的 key，避免下一次渲染再播一次
- 第一次挂载先建立 key；不要把初始化误判为从另一个页面进入
- 快速再切沿当前进度和速度继续，避免每次回到透明或偏移起点
- 从被替换的导航按钮恢复焦点时使用 `preventScroll`，不能抢走用户已移动的焦点
- 只处理可见且允许移动的正文节点；包含稳定区域的父容器应拆到合适的子节点

必须排除页头、导航、安全操作、模型预览、终端、canvas 和隐藏内容；不能对整个页面壳应用 transform

## 选择与直接操作

- 侧栏、分段选择、子页下划线与模式选择使用一致的选中反馈；指示器沿当前位置移动
- 大范围布局切换保持结构稳定，短距离运动说明活动项变化
- hover 立即可见；pressed 可用短 spring，释放后回到当前正常状态
- 危险按钮、安全操作栏和窗口系统按钮不采用影响命中位置的按压缩放
- 滑块、关节预览和相机直接拖动跟手，不加延迟弹簧
- 相机按钮切换视角、滚轮平滑与直接拖动分开处理；接到新输入时可立即打断过渡

## 折叠：保留编辑器与原生语义

优先保留原生 `details/summary` 或框架内语义等效组件；关闭后保留内容与输入状态，避免卸载重建编辑器

- `open` 与业务选择立即改变，视觉高度随后过渡
- 统一箭头、旋转方向、标题间距、hover 与 focus；容器层级按组件模块处理
- 关闭时，若焦点在将隐藏的内容中，将焦点交回 summary，使用 `preventScroll`
- 关闭过渡中的内容不可继续被键盘聚焦；完成后恢复原有 inert 状态，不覆盖本来就禁用的子内容
- 标题内独立的按钮、链接、输入框与下拉控件执行自身动作，不误触折叠
- 输入法组合期间不拦截组合输入
- 嵌套折叠或动态行改变目标高度时，跟随实际内容尺寸，不冻结旧目标
- 不支持所需原生动画接口时保留可用的原生展开收起，不牺牲基本操作

## 折叠与滚动共用一段连续过程

常见跳顶源于测量目标高度：临时移除展开高度会缩短祖先的滚动范围，浏览器立即 clamp `scrollTop`；之后再开始 spring 已经来不及

处理顺序

1. 测量前保存相关祖先的 `scrollTop`、`scrollLeft`
2. 读取当前呈现高度；临时应用目标折叠状态，测量目标高度
3. 恢复当前呈现高度，启动同一条高度 spring
4. 在同一个同步过程内恢复刚才测量造成的祖先滚动变化
5. 随面板高度实际缩短，让滚动范围自然逐步 clamp
6. 结束时清除临时高度，回到自然布局

不要在整个动画期间每帧锁定旧 `scrollTop`；只修复临时测量引起的变化，保留用户随后主动滚动的权利

不要另建一个与高度 spring 竞争的滚动引擎，也不要无条件调用 `scrollIntoView` 或强制滚到 summary

展开时同样避免临时测量挤压滚动范围；保存编辑值、选区与有意义的焦点，不能通过重建整个页面解决动画

## 锚定浮层

浮层从触发控件附近展开，变换原点对齐触发控件；下方空间不足时向上翻转，原点与方向一起调整

- 快速 spring 使用轻微位移、透明度与约 `.97 → 1` 的缩放
- 位置变化重新测量锚点，控制视口边界；不把浮层动画挂到整页
- 再次点击同一触发器关闭；外部点击、Escape 与焦点规则取决于浮层用途
- 关闭中停止接收指针，必要时将内部焦点交回触发控件
- 状态浮层不抢焦点；串口反馈的具体状态见 [机器人状态与连接](robot-state-and-connection.md)

## 减少动态与完成条件

系统或应用启用减少动态时，将活动 spring 立即完成到静态目标，取消 RAF 并清理临时样式；不能只停止在中间高度或半透明状态

验证快速主/子页切换、反向折叠、嵌套折叠、页底收起、主动滚动、键盘与减少动态；确认无旧文字叠加、无整页跳顶、无丢失编辑状态

只检查本次影响的行为；具体证据选择见 [验证](verification.md)
