# 图标与 SVG

用于普通 UI 图标、工程专用图形与已有 SVG 的视觉整改；先检查项目真实资源、使用位置与许可，再决定复用或新增；本规范不声称已提取或核实未提供的第三方图标

颜色来自 [主题规范](theme-guidelines.md)，坐标轴和模型对象来自 [可视化主题](visualization-theme.md)，资产来源登记见 [视觉资产](visual-assets.md)

## 先做适量盘点

在本次影响面查找已有 Lucide、内联 SVG、sprite、图片和框架图标；记录实际文件/包版本、许可、使用组件、重复变体与硬编码颜色；已有合适图标优先复用，不无理由加入第二套库

普通图标表达动作，工程图表达方向与关系，真实品牌资产表达权利方或硬件型号；三者不能互相冒充；工程专用图标可原创补齐，但要附可见名称或必要说明

## 普通 UI SVG 基线

| 属性 | 基线 | 实施说明 |
|---|---|---|
| viewBox | 优先 `0 0 24 24` | 已有资产先检查实际边界；不要只改 viewBox 而裁切图形 |
| 显示尺寸 | 16 / 18 / 20 / 24px | 用明确宽高避免布局跳动；视觉尺寸与按钮命中区分开 |
| stroke-width | 基准 1.75，必要时 2 | 同组一致；16px 下实际检查线条，不机械堆粗 |
| linecap / linejoin | round / round | 新普通 UI 图标统一；真实品牌标识保持批准形态 |
| stroke / fill | `currentColor` / `none` | 实心图标有明确用途再采用；注意子路径不得硬编码黑色 |
| theme | 继承语义 token | 正常、hover、pressed、focus、disabled、selected 由控件状态控制 |
| 画布 | 透明背景、合理留白 | 对齐光学中心；不能靠超大 viewBox 让同组图标忽大忽小 |

现有 disclosure 标记继续使用已确认的 8px / 1.5px 尖括号与收起向右、展开向下语义；本次普通 UI 图标基线不授权重写这套折叠行为或几何

与文字相邻的图标按光学中心对齐，不机械套用字体基线；同一操作在不同页面使用相同图形、尺寸与命名；小图标不使用细碎文字或只有放大后才可辨的孔洞

## 工程图的例外

坐标系、运动链、传感器方向和拓扑按实际关系选择画布与线宽，不强制压进 24px；使用方向箭头、实体标签、单位和必要图例，不能只有装饰性连线

XYZ 固定红/绿/蓝并带 X/Y/Z 标签；Joint Axis、Link COM、Total COM 使用既有工程定义；主题适配可调整轮廓、背景和文字，不能整体着色为 `currentColor` 抹掉工程语义

SVG 示意与实际设备数据明确区分；本包 [关节轴图标](../assets/icons/joint-axis.svg) 和 [坐标系示意](../assets/diagrams/coordinate-frame.svg) 是原创示意，来源、许可与主题使用方法见 [资产登记](visual-assets.md#随包原创资产)

## 可访问性与集成

- 装饰图标由邻近文字或按钮命名：Web 使用 `aria-hidden="true"`，不让同一个动作重复播报；其他框架用等价可访问属性
- 图标按钮在控件上给出可访问名称；必要动作条件在界面可见，不只放 tooltip
- 独立语义图形提供名称与简短说明，可用 `<title>` / `<desc>` 或框架等价方式；内联多个实例使用 id 时确保唯一
- 使用状态 token 不能代替非颜色标记；错误、断连、选中与参考各有文字、形状或线型辅助
- 外部 `<img>` 不继承页面 `currentColor`；需按嵌入方式提供实际可读的主题版本或容器，不能只修改图片元素前景
- 按钮的 focus 显示在真实命中控件上；不要让 SVG 独自承担不对应点击区的 focus 或 hover

SVG 保持自包含且只保留必要路径、基础图形与说明；检查外部 href、脚本、`foreignObject`、嵌入字体和复杂 filter 的实际用途，不将来源不明的可执行内容带入界面；有效的现有工程图不因清理而丢失标签或关系

默认不用阴影 filter、模糊或逐帧路径动画；确有用途时按 [视觉资产预算](visual-assets.md#背景效果与场景预算) 评估；主题变化更新继承颜色，不重建整套图标节点

## 验收

1. 检查 viewBox、尺寸、留白、对齐、stroke/fill/currentColor 和真实嵌入方式
2. 在 16px 与实际使用尺寸查看 Light / Dark 清晰度；工程图同时检查所有标签和方向
3. 检查 hover、pressed、focus、disabled、selected 以及适用的错误/警告状态，非颜色表达和命中区一致
4. 检查图标名称、装饰播报、键盘路径、减少动态偏好与高 DPI
5. 检查来源与许可；有复杂 SVG 或大量实例时比较实际渲染成本；不把 XML 格式通过写成视觉或性能通过
