# 工程数据与三维可视化主题

图表、工程图和模型使用独立 `viz-*` 命名层；随包 [CSS](../assets/theme/calm-control.css) 提供下表起点；除明确保留的 SerialArm 工程色外，这些映射是 V2 设计值，不是 Kudu 原始图表配置；以项目已定义的数据含义优先，不随页面随机改色

## 数据系列与冗余编码

| 数据角色 | Light / Dark | 线型、标记 | 图例名称与责任 |
|---|---|---|---|
| `viz-measured` | `#356f8d` / `#76a9d5` | 2px 实线、圆点 | 实测，来自有效反馈并表达时间戳 / 新鲜度 |
| `viz-target` | `#9a530d` / `#efb66b` | 2px 长虚线 `8 4`、方块 | 目标，用户或控制器给定值；不表示已执行 |
| `viz-estimated` | `#14756d` / `#73cbbd` | 2px 点划线 `6 3 2 3`、三角 | 估计，标识估计器及必要置信范围 |
| `viz-reference` | `#6254a5` / `#b5a9f0` | 2px 短虚线 `3 4`、菱形 | 参考，对照数据；不表示正常或验证通过 |
| `viz-predicted`，已有预测功能时 | `#85457e` / `#d7a5d4` | 点线 `1 4`、空心圆 | 预测，明确未来时间范围，不主动创造预测功能 |
| `viz-error` | `#b33e37` / `#ee766c` | 实线、十字；可独立子图 | 误差 / 残差，写明计算式和单位；数值非零本身不等于设备故障 |

可隐藏系列，但同一角色的颜色、线型和名称不能随当前排序改变；多关节用分面或稳定的次级编码，不能把第一个关节误写成 measured、第二个关节误写成 target；Reference 紫色与 Success 绿色既有色相区别，又有菱形/虚线和明确标签

## 画布、轴与时间

| Token | Light | Dark | 用法 |
|---|---|---|---|
| `viz-canvas` | `#f8f6ef` | `#121d18` | 独立于卡片的图表 / 三维底色 |
| `viz-grid` | `grid-line` | `grid-line` | 低对比度参照网格，不能承担唯一坐标信息 |
| `viz-axis` | `text-muted` | `text-muted` | 刻度、轴标签和单位 |
| `viz-selection` | `brand-solid` | `brand-solid` | 选中轮廓或十字线，不改数据系列本色 |

图表标题说明测量对象；轴标明量和单位，时间轴注明相对/绝对时间、时区或会话起点（按用途选择）；图例直接对应数据源；相邻图统一刻度格式与数值精度；双轴必须明确量纲，避免没有标识的混量纲曲线

数据缺失以断线和时间范围表示，不补零或跨空白连线；断流显示最近样本时间，异常区间使用低透明带和标签，不能遮住原曲线；大量采样按项目现有聚合策略保留峰值和异常，不用平滑制造不存在的测量值

实时更新保留容器尺寸、轴区留白、图例次序及用户选择；不要每帧改变外层布局；刷新和重绘预算沿用项目实测，不规定通用 FPS；静止 / 隐藏时按现有可见性策略暂停；交互 tooltip 可显示精确样本，必要值不能只靠 hover 获取

## 模型工程颜色保留

下表来自 SerialArm `76326c0` 的 `model-view.js`；Light / Dark 均保持同一工程色，背景与标签单独适配；其他目标项目的现有工程定义优先，不凭图标猜测对象类型

| 对象 | 色值 | 主题适配与补充编码 |
|---|---|---|
| X / Y / Z | `#ef4444 / #22c55e / #3b82f6` | 固定红 / 绿 / 蓝，附 X / Y / Z 标签 |
| 受控 Joint Axis | `#ff9f1a` | 轴线、箭头和 joint 名称；普通轴 `#8b93a3`、固定关节 origin `#b0b6c2` |
| Link COM / raw inertia | `#ff4f87` | COM 标记与 link 归属；惯性体另用形状表达 |
| Effective COM / inertia | `#ffb02e / #ffa928` | 与 raw 数据来源分别标注 |
| Total COM | `#22d3a6` | 独立总质心标记与标签，不映射 Success |
| 原有选中关节 | `#ffd166` | 保留原语义；hover、异常通过独立描边/叠加和文字表达 |

细小轴与 COM 在浅底上不一定达到非文本 3:1；保留工程色，用对比描边、深色标签底、轮廓和尺寸使对象可识别，不能以品牌换色掩盖问题；模型本体、坐标轴、参考叠影、标签与选中对象分层；参考叠影仍用独立变换，不改变实测姿态

本包 [坐标系 SVG](../assets/diagrams/coordinate-frame.svg) 是原创示意，非设备标定结果；不代表实际机器人坐标或运动许可

## 主题更新与验证

主题变化只更新现有背景、网格、标签与材质属性并请求必要重绘；不得重建 renderer / mesh、丢失相机、改变对象可见性或让隐藏画布恢复循环；保留 [模型生命周期](model-lifecycle-and-performance.md) 全部资源、失效与 generation 契约

检查双主题的系列图例、线型、单位、缺测/断流、参考与成功区别、模型轴和 COM；对比度以实际背景合成为准；随包预览仅是静态合成数据，真实遥测和三维主题切换仍按 [验证](verification.md) 在目标项目运行
