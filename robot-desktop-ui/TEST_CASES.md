# Robot Desktop UI 行为场景

用于维护本 skill 的决策行为；检查实际方案或实现及其副作用，不用精确匹配措辞、标题或源码字符串；应用交互检查见 [verification.md](references/verification.md)

## 1. 新建 SerialArm 风格工作页

请求：为机器人桌面软件新增参数与模型预览工作页，沿用本 skill

检查：采用 Kudu Calm Control Light / Dark、森林绿主操作、真实 Maple Italic 和一致导航；按任务选择 Configuration / Model Inspector 配方，保留原布局契约与真实状态；不强制安装 React 或改造控制后端

## 2. 已明确的局部视觉修正

请求：只把这个活动页的旧品牌按钮调成更亮的橙色，白字保留，其他页面不改

检查：当前明确局部要求可覆盖默认主题，仅修改该按钮和相关反馈色，不重建全局品牌、不改导航、不引入无关审批；如包含 AA 验收，报告实际橙底白字结果及符合要求的选择；其他页面继续使用 V2 森林绿

## 3. 字体与连字

请求：字体用 Maple Italic，设置中可以关闭编程连字

检查：使用真实 Italic 资源及许可，区分字形和 font-style alias；开关控制实际字体特性；hover 只覆盖复选框及标签，预览示例保持独立

## 4. 只读评审

请求：review 这段页面切换代码，先告诉我哪里有问题

材料：旧正文仍保留到新正文淡入完成后才移除的切换实现

检查：识别实际叠字路径，给出依据与建议；不修改文件，不把有内容的旧退出层当默认修复，也不借此全面重建动效系统

## 5. 快速切换与普通刷新

请求：所有切换都有 spring，但连续切页仍生硬，更新数据时还会闪

检查：继承当前呈现与速度，按稳定视图 key 区分导航和数据刷新；只让新正文进入；导航、安全栏、画布与终端保持稳定；操作不等动画完成

## 6. 折叠时跳顶

请求：参数组收起时页面突然到顶部，加平滑过渡

检查：追踪自然高度测量、滚动范围和焦点；保留编辑器与祖先滚动位置，由现有高度 spring 驱动必要 clamp；不默认增加第二套全局滚动引擎，不抢用户主动滚动

## 7. 菜单反复点击

请求：三点菜单再次点击不能关闭；串口列表太高

检查：区分 overflow menu 与 select；处理原生 invoker/light-dismiss 竞态，修复同触发器切换语义；选择器限高内部滚动、支持键盘，保留完整设备值

## 8. 快速串口扫描

请求：刷新按钮下面显示正在刷新和转圈，结束显示结果，过一会消失，别挡页面

检查：选择锚定状态浮层；扫描仅禁重复刷新，快结果仍可读，无人为延迟；成功/失败按生存期关闭；页头重建不续期，不追加同一错误的全局弹窗

## 9. 机械臂操作栏与信息布局

请求：整理机械臂状态、使能和恢复按钮；准备页工具与记录、参数检查太窄

检查：采用四象限状态栏；准备页用全宽后续工具区；参数检查移到上方全宽 inspector，左栏只做分组；不把所有区域堆成相同大卡片

## 10. 模型跨页加载

检查：覆盖数据和实际三维资源的预加载、有效实例保留、首帧挂载、暂停恢复及失效；分预览槽保存相机和可见性；串口变化不使几何缓存失效

## 11. 模型渲染卡顿

检查：先实测相关热点；复用对象、使用数值快照避免漏掉原地修改的变化；正确处理缺失 COM 和真实新姿态；不先降低画质或承诺未知 GPU 的 FPS

## 12. 不完整结果与状态文案

检查：分别表达任务结束、已测项目、缺失项目和实际下一步；保留具体诊断；不把参数已有值写成测量或验证通过，不擅自改标定算法与预算

## 13. 减少动态与直接操作

检查：正在运行的动效结束到正确状态；保留焦点与结果反馈；拖动跟随输入，遥测与业务状态不做虚假的延迟补间
